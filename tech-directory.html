T.E.C.H. Directory for Reintegration

A plain-English guide to getting online, getting hired and getting connected in Maine — built for people coming home.

Every resource here was collected in the T.E.C.H. directory spreadsheet and is shown exactly as it was written, with a simple explanation added underneath so you never have to guess what something means.

Important

This directory works without internet. Videos do not.

Once this file is saved on your device you can open it, read it, search it and browse it with no connection at all. But the videos and websites it points to live on the internet — so you will need a connection (library Wi-Fi works fine) to actually watch a video or open a website. Anything that needs a connection is marked with an orange Video — needs internet or Website tag.

How to use this directory

  1. Pick a category below. There are four, one for each part of the original spreadsheet.
  2. Or search. Type anything into the search box at the top — a city, a word like “resume”, or a website name — and matching entries appear right away.
  3. Read the grey text. Under each original entry there is a short, simple explanation of what it is and why you might want it.
  4. Open a link. A pop-up will check with you first, so you never leave this page by accident.
